# Inverso

[English](README.md) | [Русский](README.ru.md)

Приложение в строке меню macOS, которое исправляет текст, набранный не в той раскладке. Набрали `ghbdtn? rfr ltkf&` вместо `привет, как дела?` — нажмите `⇧⇧` (Shift дважды), и текст сконвертируется на месте.

Inverso — неофициальный форк LangSwitcher от LayoutSwitcher Contributors, подробнее — в разделе [О форке](#о-форке).

Изменения: [CHANGELOG.md](CHANGELOG.md). Участие в разработке и выпуск релизов: [CONTRIBUTING.md](CONTRIBUTING.md) (на английском).

## Установка

1. Скачайте `Inverso-<версия>.zip` со страницы [Releases](https://github.com/dotsentik/inverso/releases).
2. Закройте Inverso, если он запущен (иконка в строке меню → Завершить Inverso).
3. Распакуйте архив и перенесите `Inverso.app` в `/Applications` («Программы»), заменив старую копию.
4. Первый запуск: в `/Applications` правый клик по Inverso → **Открыть** → **Открыть**. Приложение не нотаризовано Apple, поэтому обычный двойной клик в первый раз заблокирован. Если macOS пишет, что приложение повреждено или его нельзя открыть, выполните:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Inverso.app
   ```
5. Выдайте доступ **Универсальный доступ** (Accessibility): Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включите Inverso (если его нет в списке, добавьте кнопкой «+»). Без этого разрешения приложение не может читать и заменять текст.

В строке меню появится иконка клавиатуры. Выдан ли доступ, видно в Настройки → Доступ.

Вручную устанавливается только первая версия. Дальше обновления приходят через приложение: иконка в строке меню → **Проверить обновления…** или автоматическая проверка раз в сутки (см. [Обновления](#обновления)).

### Универсальный доступ и обновления

macOS сохраняет разрешение Универсального доступа только для приложения с той же подписью кода. Все релизы Inverso подписываются одним и тем же сертификатом, поэтому доступ сохраняется после обновлений, в том числе установленных самим приложением.

Если конвертация перестала работать, хотя переключатель включён: в списке Универсального доступа выделите Inverso, удалите его кнопкой «−», добавьте `/Applications/Inverso.app` кнопкой «+», включите и перезапустите приложение.

### Переход с LangSwitcher

До версии 1.2.7 Inverso назывался LangSwitcher. У него новый идентификатор пакета, поэтому LangSwitcher не может обновиться до Inverso сам; установите его вручную один раз:

1. Завершите LangSwitcher и удалите его из `/Applications`.
2. Уберите LangSwitcher из списка Универсального доступа: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ, выделите его и нажмите «−».
3. Установите Inverso вручную (см. [Установка](#установка)).
4. Выдайте Inverso доступ к Универсальному доступу.
5. При желании: журнал конвертаций копируется при первом запуске, если каталога `~/Library/Application Support/Inverso` ещё нет. Чтобы скопировать его вручную, завершите Inverso и скопируйте `~/Library/Application Support/LangSwitcher/conversion_log.sqlite` в `~/Library/Application Support/Inverso/`.

## Использование

1. Наберите текст в любом приложении.
2. Нажмите `⇧⇧`. Если текст выделен, конвертируется выделение; иначе умная конвертация выбирает текст перед курсором.
3. В меню иконки в строке меню: Конвертировать текст, список раскладок (щелчок переключает на неё), Настройки… (`⌘,`), О Inverso, Проверить обновления…, Завершить (`⌘Q`).

## Что умеет

### Конвертация

- **Конвертирует по физическим клавишам** между любыми двумя включёнными раскладками: `ghbdtn` ↔ `привет`, `руддщ` ↔ `hello`.
- **Использует раскладки, установленные в macOS.** Таблицы символов читаются из системных раскладок (`UCKeyTranslate`), поэтому работает любая раскладка. Встроенные таблицы для U.S./ABC/British, русской, украинской, немецкой, французской и испанской раскладок — запасной вариант, если системную таблицу прочитать не удалось.
- **Определяет исходную раскладку** по тексту; при равенстве побеждает текущая активная раскладка. Целевая — первая по приоритету раскладка с другой письменностью или та, что вы выбрали для этой раскладки.
- **Знаки препинания**: после буквы конвертируются вместе со словом (`ltkf&` → `дела?`); в начале слова или отдельно остаются как набраны, если только клавиша не даёт букву в целевой раскладке (`;` → `ж`).

### Умная конвертация (ничего не выделено)

- **Жадный (вся фраза)** — по умолчанию. Выделяет от курсора до начала строки (`⌘⇧←`), находит, где начинается часть в неправильной раскладке, и конвертирует только её: в `Привет ghbdtn rfr` изменится только `ghbdtn rfr`. Строка, где все или почти все слова в неправильной раскладке, конвертируется целиком.
- **Только последнее слово** — выделяет слово перед курсором (`⌥⇧←`) и конвертирует его, если оно похоже на набранное не в той раскладке.
- **Отключено** — конвертируется только явно выделенный текст.

Если конвертировать нечего, выделение снимается и курсор остаётся на месте.

### Где работает

- **Большинство приложений**: текст читается и заменяется через Accessibility API; если приложение его не поддерживает — через `⌘C` / `⌘V`.
- **Electron-приложения** обрабатываются только через буфер обмена, потому что они сообщают об успешной записи через Accessibility, но не применяют её: Obsidian, Visual Studio Code, Slack, Discord, Notion и любое другое приложение, внутри которого есть `Electron Framework.framework`.
- **Spotlight и диалоги Открыть/Сохранить** получают фокус клавиатуры, не становясь активным приложением. Inverso распознаёт их, читает текст из них и вводит сконвертированный текст набором.
- **Буфер обмена** сохраняется перед использованием и восстанавливается после, если только другое приложение не записало в него что-то за это время.

### Ограничения

- **В терминалах конвертация не поддерживается** (Terminal, iTerm2, Ghostty, Warp, kitty, Alacritty, WezTerm): там горячая клавиша не нажимает никаких клавиш, не трогает буфер обмена и не меняет текст; на экране появляется подсказка «В терминале не поддерживается».

### Обратная связь

- **Подсказка на экране (HUD)** — по умолчанию: небольшая панель вверху экрана, на котором находится курсор мыши, например `ghbdtn → привет · RU`, примерно на секунду. Не забирает фокус, учитывает «Уменьшить движение» и «Уменьшить прозрачность», озвучивается VoiceOver.
- Вместо неё можно выбрать **Уведомление** (Центр уведомлений) или **Ничего**.
- **Звук** («Tink») после конвертации, по умолчанию включён.

### Переключение раскладки после конвертации

После конвертации системная раскладка переключается на ту, в которую сконвертирован текст. В настройках есть три режима (всегда / если последнее слово было конвертировано / если хоть одно слово потребовало конвертации); в текущей версии все три работают одинаково и переключают раскладку после каждой конвертации.

## Настройки

В окне настроек (`⌘,`) пять разделов, переключаются сегментами вверху или `⌘1`…`⌘5`:

- **Основные** — язык интерфейса (Как в системе, English, Русский; меняется сразу), запуск при входе в систему, автоматическая проверка обновлений, что показывать после конвертации (Подсказку на экране, Уведомление, Ничего), звук, режим умной конвертации, режим переключения раскладки, число конвертаций.
- **Раскладки** — раскладки, включённые в macOS, в порядке приоритета. Перетаскивайте строки или используйте `⌥⌘↑` / `⌥⌘↓`; снимите галочку (или нажмите Пробел), чтобы не использовать раскладку; «Конвертировать в» задаёт целевую раскладку (Авто — по приоритету); «Обновить из системы» подхватывает изменения.
- **Клавиши** — двойной Shift (`⇧⇧`, по умолчанию) или своё сочетание (`⌥S`, пока не записано другое).
- **Доступ** — состояние Универсального доступа, кнопки для открытия Системных настроек и запроса доступа.
- **Журнал** — по умолчанию выключен. Если включить, конвертации сохраняются в локальной базе SQLite (`~/Library/Application Support/Inverso/conversion_log.sqlite`), по умолчанию 100 записей или без ограничения. Записи можно отмечать как верные/неверные, удалять и экспортировать в JSON.

## Сеть и конфиденциальность

- Никакой аналитики, телеметрии и учётных записей.
- Единственный сетевой запрос — проверка обновлений: Inverso скачивает [`appcast.xml`](appcast.xml) с GitHub (`raw.githubusercontent.com`) и, если вы согласитесь обновиться, архив релиза с GitHub Releases. Отключается в Настройки → Основные → «Проверять обновления автоматически»; тогда приложение не обращается к сети, пока вы сами не выберете «Проверить обновления…».
- Журнал конвертаций по умолчанию выключен и никогда не покидает ваш Mac.
- Собственные логи приложения (unified logging, подсистема `com.inverso.app`) записывают набранный текст только на уровне debug и с пометкой private.

## Обновления

- Раз в сутки Inverso проверяет, не вышла ли новая версия (через [Sparkle](https://sparkle-project.org)). Если вышла — показывает описание и предлагает установить; обновление скачивается, его подпись EdDSA проверяется, приложение заменяется и перезапускается.
- Проверить вручную: иконка в строке меню → **Проверить обновления…**.
- Автоматическую проверку можно отключить в Настройки → Основные.
- Релизы с архивами лежат на [GitHub Releases](https://github.com/dotsentik/inverso/releases); лента обновлений — [`appcast.xml`](appcast.xml) в ветке `main`.

### Если появилась «Update Error»

Sparkle показывает «Update Error», когда не может загрузить ленту обновлений или архив либо архив не прошёл проверку:

- **репозиторий приватный:** лента на `raw.githubusercontent.com` и загрузка релиза отвечают 404 на анонимные запросы;
- **нет релиза или ленты:** в GitHub Release нет zip или `appcast.xml` с записью ещё не в `main`;
- **неверная подпись:** архив подписан не тем ключом, публичная часть которого записана в приложении (`SUPublicEDKey`); Sparkle отказывается его устанавливать;
- **кэш:** `raw.githubusercontent.com` кэширует файлы до ~5 минут, поэтому только что опубликованная лента может быть ещё старой; повторите позже.

Чтобы узнать причину, запустите в клоне репозитория:

```bash
scripts/check-feed.sh --installed-build <ваша сборка>
```

Номер сборки — последнее число версии в окне «О Inverso» («Версия 1.2.7» — сборка 7). Приложение также пишет в лог домен и код ошибки и HTTP-статус ленты: `log show --last 10m --predicate 'subsystem == "com.inverso.app"'`.

## Требования

- macOS 15 (Sequoia) или новее
- Универсальная сборка: работает нативно на Mac с Apple Silicon и Intel (`arm64` + `x86_64`)
- Разрешение Универсального доступа
- Для сборки: Xcode 26 или новее (Swift 6, иконка приложения — файл Icon Composer `.icon`)

## Сборка

```bash
xcodebuild build \
  -project Inverso.xcodeproj \
  -scheme Inverso \
  -configuration Release \
  -destination 'platform=macOS' \
  -derivedDataPath build \
  CODE_SIGN_IDENTITY="-"
```

Приложение появится в `build/Build/Products/Release/Inverso.app`. Xcode загружает [Sparkle](https://github.com/sparkle-project/Sparkle) 2.10.0 через Swift Package Manager и встраивает `Sparkle.framework` в `Contents/Frameworks`.

Тесты:

```bash
xcodebuild test \
  -project Inverso.xcodeproj \
  -scheme Inverso \
  -destination 'platform=macOS' \
  CODE_SIGN_IDENTITY="-" \
  CODE_SIGNING_REQUIRED=NO \
  CODE_SIGNING_ALLOWED=NO
```

CI (GitHub Actions) только запускает эти тесты — при push в `main` и в pull request; релизы собираются локально.

### Параметры сборки

- Swift 6 с полной строгой проверкой конкурентности; минимальная система macOS 15.0; в проекте `ARCHS = arm64` для локальных сборок, `scripts/release.sh` собирает универсальную (`arm64 x86_64`).
- Без App Sandbox (чтение и замена текста в других приложениях требуют Accessibility и синтетических нажатий клавиш).
- Hardened Runtime включён. В `Inverso/Inverso.entitlements` есть `com.apple.security.cs.disable-library-validation`: без Team ID от Apple (подпись ad hoc или самоподписанным сертификатом) library validation не даёт загрузить встроенный `Sparkle.framework`.
- Версия: **1.2.N, где N = `CURRENT_PROJECT_VERSION`** (`CFBundleVersion`, её сравнивает Sparkle). `MARKETING_VERSION` видна пользователю («Версия 1.2.7» в окне «О Inverso»); каждый релиз поднимает обе: 1.2.7 — сборка 7, следующий — 1.2.8 и сборка 8. `scripts/release.sh` останавливается, если они не совпадают. Часть `1.2` меняется только вручную при крупных изменениях (правило становится X.Y.N, N по-прежнему номер сборки); подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md#versioning).

## Выпуск релиза

Полный порядок, включая ветки, коммиты и версии, — в [CONTRIBUTING.md](CONTRIBUTING.md#releasing).

`scripts/release.sh` собирает универсальный релиз (`ARCHS`, по умолчанию `arm64 x86_64`; `SIGN_IDENTITY`, по умолчанию `Inverso Release`, `-` — ad hoc). Он подменяет в компиляторах каталоги проекта и сборки на `/src` и `/build`, удаляет debug map, подписывает приложение, проверяет архитектуры, подпись, entitlements, маркеры обязательных функций, версию в `Info.plist` и отсутствие путей `/Users/` в каждом срезе и во всём приложении. Он создаёт `dist/Inverso-<версия>.zip` (+ `.sha256`, `INSTALL.txt`), `dist/appcast.xml` с одной подписанной записью и `dist/release-notes.md` из `CHANGELOG.md`. Он ничего не публикует и не меняет `appcast.xml` в корне репозитория.

**Правило:** запись о версии попадает в закоммиченный `appcast.xml` только после того, как zip загружен в GitHub Release. До этого `appcast.xml` — валидная лента без записей, и установленные копии видят «обновлений нет», а не ошибку.

1. Поднимите `CURRENT_PROJECT_VERSION` и выставьте `MARKETING_VERSION` = `1.2.<сборка>`, обновите `CHANGELOG.md`.
2. Сделайте коммиты с изменениями и соберите релиз: `scripts/release.sh` (получаются `dist/Inverso-<версия>.zip`, `dist/appcast.xml`, `dist/release-notes.md`).
3. Запушьте `main` и поставьте аннотированный тег `v<версия>` на коммит с этой версией.
4. Репозиторий должен быть публичным, иначе Sparkle не скачает ни ленту, ни zip.
5. Создайте GitHub Release для тега с zip и описанием:
   ```bash
   gh release create v<версия> dist/Inverso-<версия>.zip --title "Inverso <версия>" --notes-file dist/release-notes.md
   ```
6. Запустите `scripts/apply-appcast.sh` (он проверяет запись, размер zip, подпись, номер сборки и то, что zip скачивается, и копирует `dist/appcast.xml` в корень), затем отдельным коммитом «Publish appcast for v<версия>» закоммитьте `appcast.xml` и запушьте.
7. Подождите до 5 минут (raw.githubusercontent.com кэширует файлы) и запустите `scripts/check-feed.sh --installed-build <предыдущая сборка>`. Он выводит PASS/FAIL по каждой проверке и завершается с кодом 1 при любой ошибке.
8. Проверьте на реальном Mac: установите предыдущую сборку (с Sparkle), выберите **Проверить обновления…**, убедитесь, что обновление найдено, скачано и установлено, приложение перезапустилось, а Универсальный доступ не сбросился.

> **Внимание.** Ключ подписи обновлений (EdDSA) и сертификат «Inverso Release» храните вне репозитория и сделайте резервные копии: `generate_keys -x <файл вне репозитория>` и экспорт в `.p12`. Если ключ потерян, выпустить обновление для уже установленных копий будет невозможно.

- **Ключ подписи обновлений (EdDSA).** Создаётся один раз утилитой Sparkle `generate_keys` (после `scripts/release.sh` лежит в `build/dist-derived/SourcePackages/artifacts/sparkle/Sparkle/bin/`); приватный ключ хранится в login Keychain, публичный — `SUPublicEDKey` в `Info.plist`. Резервная копия: `generate_keys -x <файл вне репозитория>`, восстановление на другом Mac: `generate_keys -f <файл>`.
- **Сертификат подписи кода.** Самоподписанный сертификат «Inverso Release» в login Keychain. Сохраните его: релизы, подписанные другим сертификатом, теряют доступ Универсального доступа при обновлении. Экспорт: Связка ключей → Мои сертификаты → Inverso Release → Файл → Экспортировать объекты… (`.p12`, с паролем); храните файл вне репозитория.

## О форке

Inverso — неофициальный форк проекта LangSwitcher от LayoutSwitcher Contributors, <https://github.com/reg2005/langSwitcher>, распространяемого по лицензии MIT. Автор оригинального проекта не связан с этим форком и не отвечает за него. О проблемах с Inverso сообщайте здесь, а не в оригинальный проект.

Основные отличия от оригинала:

- Swift 6 со строгой проверкой конкурентности.
- Таблицы символов читаются из раскладок, установленных в macOS (`UCKeyTranslate`), а не только из фиксированных таблиц.
- Интерфейс на SwiftUI: меню в строке меню и окно настроек с разделами.
- Подсказка на экране (HUD) после конвертации вместо уведомлений (уведомления остались как вариант).
- Локализация: английский и русский, с выбором языка в приложении.
- Чтение и замена выделения через Accessibility API, с буфером обмена как запасным вариантом и для Electron-приложений.
- Конвертация в Spotlight и диалогах Открыть/Сохранить.
- Автоматические обновления через Sparkle.
