# Inverso

[English](README.md) | [Русский](README.ru.md)

Приложение в строке меню macOS, которое исправляет текст, набранный не в той раскладке. Набрали `ghbdtn? rfr ltkf&` вместо `привет, как дела?` — нажмите `⇧⇧` (Shift дважды), и текст сконвертируется на месте.

## Установка

1. Скачайте `Inverso-<версия>.zip` со страницы [Releases](https://github.com/dotsentik/inverso/releases), распакуйте и перенесите `Inverso.app` в `/Applications` («Программы»).
2. Первый запуск: правый клик по Inverso → **Открыть** → **Открыть**. Приложение не нотаризовано Apple, поэтому обычный двойной клик в первый раз заблокирован. Если macOS пишет, что приложение повреждено, выполните:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Inverso.app
   ```
3. Выдайте доступ **Универсальный доступ**: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включите Inverso (если его нет в списке, добавьте кнопкой «+»). Без этого приложение не может читать и заменять текст. Статус виден в Настройки → Доступ.

Вручную устанавливается только первая версия, дальше обновления приходят из приложения (см. [Обновления](#обновления)). Все релизы подписаны одним сертификатом, поэтому доступ сохраняется после обновлений. Если конвертация перестала работать, хотя переключатель включён, удалите Inverso из списка кнопкой «−», добавьте заново и перезапустите приложение.

## Использование

1. Наберите текст в любом приложении.
2. Нажмите `⇧⇧`. Выделенный текст конвертируется; если ничего не выделено, умная конвертация берёт текст перед курсором.
3. В меню иконки в строке меню можно сконвертировать текст, переключить раскладку, открыть Настройки (`⌘,`) и проверить обновления.

## Возможности

- **Конвертирует по физическим клавишам** между любыми двумя включёнными раскладками: `ghbdtn` ↔ `привет`, `руддщ` ↔ `hello`. Таблицы символов читаются из раскладок, установленных в macOS, поэтому работает любая раскладка; запасной вариант — встроенные таблицы для U.S./ABC/British, русской, украинской, немецкой, французской и испанской.
- **Определяет исходную раскладку** по тексту. Целевая — первая по приоритету раскладка с другой письменностью или та, что вы выбрали для этой раскладки. После конвертации системная раскладка переключается на целевую.
- **Знаки препинания** после буквы конвертируются вместе со словом (`ltkf&` → `дела?`); в начале слова остаются как набраны, если только клавиша не даёт букву в целевой раскладке (`;` → `ж`).
- **Умная конвертация** (ничего не выделено): *Вся фраза* (по умолчанию) конвертирует только ту часть строки перед курсором, что набрана не в той раскладке: в `Привет ghbdtn rfr` изменится только `ghbdtn rfr`; *Только последнее слово*; или *Отключено*.
- **Где работает**: в большинстве приложений через Accessibility API с запасным вариантом `⌘C` / `⌘V`; в Electron-приложениях (VS Code, Slack, Discord, Obsidian, Notion…) через буфер обмена, который потом восстанавливается; в Spotlight и в диалогах Открыть/Сохранить.
- **Не поддерживаются терминалы** (Terminal, iTerm2, Ghostty, Warp, kitty, Alacritty, WezTerm): горячая клавиша там ничего не меняет, а подсказка на экране об этом сообщает.
- **Обратная связь**: небольшая подсказка вверху экрана (например, `ghbdtn → привет · RU`), либо уведомление, либо ничего; по желанию звук.

## Настройки

Открываются через `⌘,`.

- **Основные**: язык интерфейса (Системный, English, Русский), запуск при входе, проверка обновлений, вид обратной связи, звук, режим умной конвертации.
- **Раскладки**: включённые раскладки по приоритету и целевая раскладка для каждой.
- **Горячая клавиша**: двойной Shift (по умолчанию) или своё сочетание.
- **Доступ**: статус Универсального доступа.
- **Журнал**: по умолчанию выключен; если включить, конвертации сохраняются в локальной базе, их можно оценивать и экспортировать в JSON.

## Обновления

Inverso раз в сутки проверяет обновления через [Sparkle](https://sparkle-project.org) и устанавливает их после вашего согласия; каждая загрузка проверяется по подписи EdDSA. Проверить вручную: иконка в строке меню → **Проверить обновления…**. Автоматическую проверку можно отключить в Настройки → Основные.

Если при обновлении появляется «Update Error», см. [Troubleshooting updates](CONTRIBUTING.md#troubleshooting-updates).

## Конфиденциальность

Никакой аналитики, телеметрии и учётных записей. Единственный сетевой запрос — проверка обновлений (`appcast.xml` с GitHub и, если вы согласитесь, архив релиза); если её отключить, приложение не делает запросов, пока вы не проверите обновления вручную. Журнал конвертаций по умолчанию выключен и не покидает ваш Mac.

## Требования

macOS 15 (Sequoia) или новее; Apple Silicon и Intel (универсальная сборка); разрешение Универсального доступа.

## О форке

Inverso — неофициальный форк [LangSwitcher](https://github.com/reg2005/langSwitcher) от LayoutSwitcher Contributors, распространяется по лицензии MIT. Автор оригинального проекта не связан с этим форком и не отвечает за него; о проблемах Inverso сообщайте здесь, а не в оригинальный проект.

Основные отличия от оригинала:

- Swift 6 со строгой проверкой конкурентности.
- Таблицы символов читаются из раскладок, установленных в macOS, а не только из фиксированных таблиц.
- Меню в строке меню и окно настроек на SwiftUI; интерфейс на английском и русском.
- Подсказка на экране после конвертации вместо уведомлений.
- Доступ к тексту через Accessibility API с запасным вариантом через буфер обмена; Electron-приложения, Spotlight и диалоги Открыть/Сохранить.
- Автоматические обновления через Sparkle.
