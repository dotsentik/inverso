Програма в рядку меню macOS, яка виправляє текст, набраний не в тій розкладці. Набрали `ghbdtn? rfr ltkf&` замість `привет, как дела?` — натисніть `⇧⇧` (Shift двічі), і текст буде перетворено на місці.

Inverso — неофіційний форк LangSwitcher, див. [Про форк](#about-this-fork). Зміни: [CHANGELOG.md](CHANGELOG.md). Збірка, участь у розробці та випуск релізів: [CONTRIBUTING.md](CONTRIBUTING.md) (англійською).

## Встановлення

1. Завантажте `Inverso-<версія>.zip` зі сторінки [Releases](https://github.com/dotsentik/inverso/releases), розпакуйте його й перенесіть `Inverso.app` до `/Applications`.
2. Перший запуск: клацніть правою кнопкою на Inverso → **Open** → **Open**. Програма не нотаризована Apple, тому звичайний подвійний клік перший раз заблоковано. Якщо macOS пише, що програму пошкоджено, виконайте:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Inverso.app
   ```
3. Надайте доступ **Accessibility**: System Settings → Privacy & Security → Accessibility → увімкніть Inverso (якщо його немає в списку, додайте кнопкою «+»). Без цього програма не може читати й замінювати текст. Статус видно в Settings → Permissions.

Вручну встановлюється лише перша версія; наступні встановлюються з програми (див. [Оновлення](#updates)). Усі релізи підписано одним сертифікатом, тому доступ зберігається після оновлень. Якщо перетворення перестало працювати, хоча перемикач увімкнено, видаліть Inverso зі списку кнопкою «−», додайте знову й перезапустіть програму.

## Використання

1. Наберіть текст у будь-якій програмі.
2. Натисніть `⇧⇧`. Виділений текст буде перетворено; якщо нічого не виділено, розумне перетворення бере текст перед курсором.
3. Через іконку в рядку меню можна перетворити текст, перемкнути розкладку, відкрити Settings (`⌘,`) і перевірити оновлення.

## Можливості

- **Перетворює за фізичними клавішами** між будь-якими двома ввімкненими розкладками: `ghbdtn` ↔ `привет`, `руддщ` ↔ `hello`. Таблиці символів зчитуються зі встановлених у macOS розкладок, тож працює будь-яка розкладка; запасний варіант — вбудовані таблиці для U.S./ABC/British, російської, української, німецької, французької та іспанської.
- **Визначає вихідну розкладку** за текстом. Цільова — перша за пріоритетом розкладка з іншою писемністю або та, яку ви обрали для цієї розкладки. Після цього системна розкладка перемикається на цільову.
- **Розділові знаки** після літери перетворюються разом зі словом (`ltkf&` → `дела?`); на початку слова залишаються як набрано, якщо тільки клавіша не дає літеру в цільовій розкладці (`;` → `ж`).
- **Розумне перетворення** (нічого не виділено): *Entire Phrase* (за замовчуванням) перетворює лише ту частину рядка перед курсором, що набрана не в тій розкладці, тож у `Привет ghbdtn rfr` зміниться тільки `ghbdtn rfr`; *Last Word Only*; або *Disabled*.
- **Де працює**: у більшості програм через Accessibility API із запасним варіантом `⌘C` / `⌘V`; в Electron-програмах (VS Code, Slack, Discord, Obsidian, Notion…) через буфер обміну, який потім відновлюється; у Spotlight і діалогах Open/Save.
- **Не підтримуються термінали** (Terminal, iTerm2, Ghostty, Warp, kitty, Alacritty, WezTerm): гаряча клавіша там нічого не змінює, а підказка на екрані про це повідомляє.
- **Зворотний зв'язок**: невелика підказка вгорі екрана (наприклад, `ghbdtn → привет · RU`), або сповіщення, або нічого; за бажанням звук.

## Налаштування

Відкриваються через `⌘,`.

- **General**: мова інтерфейсу (System, English, Русский), запуск під час входу, перевірка оновлень, вигляд зворотного зв'язку, звук, режим розумного перетворення.
- **Layouts**: ввімкнені розкладки за пріоритетом і цільова розкладка для кожної.
- **Shortcut**: подвійний Shift (за замовчуванням) або власна комбінація.
- **Permissions**: статус Accessibility.
- **Log**: за замовчуванням вимкнено; якщо ввімкнути, перетворення зберігаються в локальній базі, їх можна оцінювати та експортувати в JSON.

## Оновлення

Inverso раз на добу перевіряє оновлення через [Sparkle](https://sparkle-project.org) і встановлює їх після вашої згоди; кожне завантаження перевіряється за підписом EdDSA. Перевірити вручну: іконка в рядку меню → **Check for Updates…**. Автоматичну перевірку можна вимкнути в Settings → General.

Якщо під час оновлення з'являється «Update Error», див. [Troubleshooting updates](CONTRIBUTING.md#troubleshooting-updates).

## Конфіденційність

Жодної аналітики, телеметрії та облікових записів. Єдиний мережевий запит — перевірка оновлень (`appcast.xml` з GitHub і, якщо ви погодитеся, архів релізу); якщо її вимкнути, програма не робить запитів, доки ви не перевірите оновлення вручну. Журнал перетворень за замовчуванням вимкнено, і він не залишає ваш Mac.

## Вимоги

macOS 15 (Sequoia) або новіша; Apple Silicon та Intel (універсальна збірка); дозвіл Accessibility.

## Про форк

Inverso — неофіційний форк [LangSwitcher](https://github.com/reg2005/langSwitcher) від LayoutSwitcher Contributors, що поширюється за ліцензією MIT. Автор оригінального проєкту не пов'язаний із цим форком і не відповідає за нього; про проблеми Inverso повідомляйте тут, а не в оригінальний проєкт.

Основні відмінності від оригіналу:

- Swift 6 зі строгою перевіркою конкурентності.
- Таблиці символів зчитуються зі встановлених у macOS розкладок, а не лише з фіксованих таблиць.
- Меню в рядку меню та вікно налаштувань на SwiftUI; інтерфейс англійською та російською.
- Підказка на екрані після перетворення замість сповіщень.
- Доступ до тексту через Accessibility API із запасним варіантом через буфер обміну; Electron-програми, Spotlight і діалоги Open/Save.
- Автоматичні оновлення через Sparkle.
